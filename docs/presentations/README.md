## Usage

Open any .html file directly in a browser. No server required.

Navigation:

- Arrow keys or click to advance slides
- N toggles speaker notes
- Home / End jumps to first / last slide

Decks use embedded styles and JavaScript. External Red Hat Design Tokens and fonts load from CDN when network access is available.
