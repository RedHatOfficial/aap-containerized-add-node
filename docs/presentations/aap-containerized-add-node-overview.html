04 · topology options

Topology options to suit customer and environments.

All patterns use receptor on default TCP port 27199. Direction controls firewall requirements and whether existing services need a restart.

Direct outbound

EN → Controller
Default. New node dials out; existing receptor configs stay untouched.

Segmented network

EN → Hop → Controller
Use hop nodes for DMZ, air-gap bridges, or restricted routes.

Controller initiated

Controller → EN
Fallback when EN cannot dial out. Opt-in; controller receptor restarts per node.

05 · Online and Offline Options

Choose access path based on SSH reachability and trust boundary.

Online / ProxyJump

  • Needs SSH from control host to Controller and new nodes.
  • ProxyJump adds bastion routing for SSH.
  • Provides immediate, centralized execution and verification.
  • Receptor mesh remains direct between peers.

Offline bundle

  • Needs SSH to Controller only for bundle generation.
  • Transfer bundle through approved secure channel.
  • Provides local install on target without control-host SSH.
  • Bundle contains TLS private keys; delete after use.
Both options reuse the same setup tree, inventory model, certificates, and receptor configuration. Only delivery path changes.
