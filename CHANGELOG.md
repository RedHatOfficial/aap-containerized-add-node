# Changelog

Release notes are maintained with **antsibull-changelog**.

- Generated release notes: [CHANGELOG.rst](CHANGELOG.rst)
- Unreleased fragments: [`changelogs/fragments/`](changelogs/fragments/)
- Config: [`changelogs/config.yaml`](changelogs/config.yaml)

Do not edit this file for release content. Add a fragment under
`changelogs/fragments/` in your PR (see [CONTRIBUTING.md](CONTRIBUTING.md)).

Releases are published automatically on the **1st and 15th of every month**
when there are fragments to consume. A **manual release** is also available
between those dates when something should ship sooner
(see [CONTRIBUTING.md](CONTRIBUTING.md#release-process)).
