# SDLC Status Values

Reference for valid status values across artifact types.

## Phases

| Status | Meaning |
|--------|---------|
| Planned | Scoped but not started |
| In Progress | Active development |
| Complete | All requirements implemented |
| Future | Not yet scoped |

## Requirements (REQ)

| Status | Meaning |
|--------|---------|
| Open | Not yet implemented |
| Implemented | Code complete and tested |
| Deferred | Postponed to future phase |

## Decision Requests (DR)

| Status | Meaning |
|--------|---------|
| Open | Awaiting decision |
| Decided | Decision made |
| Deferred | Postponed |

### DR Priority

| Priority | Meaning |
|----------|---------|
| Blocking | Blocks all progress |
| High | Blocks current phase |
| Medium | Needed soon |
| Low | Nice to have |

## Architecture Decision Records (ADR)

| Status | Meaning |
|--------|---------|
| Proposed | Under review |
| Accepted | Ratified |
| Deprecated | No longer applies |
| Superseded | Replaced by another ADR |
