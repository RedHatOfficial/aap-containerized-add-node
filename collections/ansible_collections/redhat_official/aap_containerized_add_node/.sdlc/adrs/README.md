## Creating a New ADR

1. Copy `../templates/adr.md`
2. Number sequentially: `ADR-006-title.md`
3. Fill in context, decision, alternatives, consequences
4. Set status to `Proposed`
5. After review, update to `Accepted`

## ADR Lifecycle

```
Proposed → Accepted → [Deprecated | Superseded]
```
