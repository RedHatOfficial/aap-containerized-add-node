# Support Model

## Important Notice

**This collection is not part of the official Ansible Automation Platform (AAP) product.**

## Support Options

### With Red Hat Support Exception (SE)

For customers requiring Red Hat Support coverage:

1. **Request a Support Exception** via your TAM or Red Hat account team
2. Reference this collection and your specific use case (adding execution nodes without full installer re-run)
3. If approved, you may open support cases referencing your SE number

**What the SE covers:**
- Use of this collection alongside a supported AAP installation
- Troubleshooting integration issues with your AAP environment

**What the SE does not cover:**
- Bugs in the collection code itself (report via GitHub Issues)
- Unsupported configurations or platforms

### Without Support Exception

This collection is provided **as-is** with community support only:

- Report issues via [GitHub Issues](https://github.com/RedHatOfficial/aap-containerized-add-node/issues)
- Ask questions via [GitHub Discussions](https://github.com/RedHatOfficial/aap-containerized-add-node/discussions)
- No SLA or guaranteed response time

## Documentation Requirements

If using with a Support Exception:

- Reference your SE number in any related support cases
- Document which nodes were added via this collection
- Maintain inventory of collection-managed vs installer-managed nodes

## Upstream Path

This collection implements functionality that may be incorporated into the official containerized installer in a future AAP release. See [INSTALLER_PLAN.md](INSTALLER_PLAN.md) for the upstream contribution plan.

## Contact

- **TAM/Account Team**: Request Support Exception
- **GitHub Issues**: Bug reports and feature requests
- **GitHub Discussions**: Questions and community support
